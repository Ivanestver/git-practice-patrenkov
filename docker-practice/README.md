# Экзамен по Docker
## Назначение приложения
Данное приложение является экзаменационным заданием. Принцип работы очень прост: приложение считает, сколько раз была открыта главная страница.
Приложение состоит из двух частей: веб-приложение на Flask и база данных на redis: Flask отображает число открытий, а redis хранит это число.
Реализовано сохранение данных в томах, т.е. данные не удалятся, если удалить контейнеры.

## Запуск приложения
1. Клонировать проект локально.
2. Перейти в директорию с docker-compose.yml.
3. Ввести docker compose up -d.
4. В браузере открыть http://localhost:5000.
5. Перезагружать страницу и смотреть на увеличение числа.
6. Если ввести команду docker compose down, а затем выполнить п.п.3-5, то можно увидеть, что число не сбросится.

## Использованные команды для проверок
* docker images
* docker ps -a
* docker logs -f <container_name_or_id>
* docker exec -it <container_name_or_id> sh
